# Connect on Windows

Your administrator will send you one private subscription link. Do not forward it to anyone.

1. Download Hiddify for Windows from its [official page](https://hiddify.com/app/How-to-install-Hiddify-app/).
2. Install and open Hiddify.
3. Copy the complete subscription link.
4. Click `New profile` or `+` and choose import from clipboard.
5. Paste the link manually if it was not detected.
6. Select the imported profile, choose VPN/TUN mode, and click the connection button.
7. Approve the Windows network or VPN component prompt if it appears.

The VPN is active when Hiddify shows `Connected`.

To check it, open `https://www.cloudflare.com/cdn-cgi/trace`. The `ip` line should show the VPN server address supplied by your administrator.

If VPN/TUN mode cannot start, close Hiddify and run it once as Administrator. If it still fails, send the administrator the time, network type, operator, Windows version, Hiddify version, and a screenshot. Do not post the subscription link publicly.
