# Connect on macOS

Your administrator will send you one private subscription link. Do not forward it to anyone.

1. Download Hiddify for macOS from its [official page](https://hiddify.com/app/How-to-install-Hiddify-app/).
2. Move Hiddify to `Applications` and open it.
3. If macOS blocks the first launch, open `System Settings` → `Privacy & Security` and approve that specific application.
4. Copy the complete subscription link.
5. Click `New profile` or `+` and choose import from clipboard.
6. Select the imported profile and click the connection button.
7. Approve the macOS VPN configuration prompt.

The VPN is active when Hiddify shows `Connected` and macOS displays the VPN indicator.

To check it, open `https://www.cloudflare.com/cdn-cgi/trace`. The `ip` line should show the VPN server address supplied by your administrator.

If it does not connect, try another network and send the administrator the time, network type, operator, macOS version, Hiddify version, and a screenshot. Do not post the subscription link publicly.
